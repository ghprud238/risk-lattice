## 2. Dockerization & Non-Conflicting Port Architecture

### 2.1 The Port 5000 Collision on macOS
When deploying local microservices or Docker containers on macOS (Monterey, Ventura, Sonoma, Sequoia), port `5000` is **bound by default to the AirPlay Receiver service** (`ControlCenter`, PID 758 listening on `TCP *:5000 / *:commplex-main`). Binding any Docker container or local server to `5000` produces an immediate system failure:
```
bind: address already in use
```
Simultaneously, local development port `8000` was occupied by an existing local application.

### 2.2 Clean Port Allocation
To guarantee collision-free deployment across macOS, Linux, and Windows, RiskLattice was re-routed to dedicated ports:
- **Frontend Web UI**: **`http://localhost:5050`** (Mapped `5050:5050`)
- **Backend FastAPI API & OpenAPI Docs**: **`http://localhost:5051`** (Mapped `5051:5051`, Swagger at `/docs`)

Both ports were verified as clean, free, and unallocated via `lsof -i :5050`, `lsof -i :5051`, and the updated `backend/scripts/doctor.py` diagnostic tool.

### 3.1 Pillar 1: Enterprise Data Connectors (The Ingestion Layer)

### 3.2 Pillar 2: Model Risk Management & Regulatory Clearance (The SR 11-7 Hurdle)
A bank's Chief Risk Officer cannot deploy RiskLattice without approval from their internal **Model Risk Management (MRM)** committee, governed by **Federal Reserve SR 11-7 / OCC 2011-12 guidelines**:
- **Analytical Convergence Proofs**:
  - Formal mathematical proof showing that the damping factor $\alpha = 0.65$ guarantees the spectral radius $\rho(\alpha \mathbf{W}) < 1$, preventing cyclic runaway.
- **Crisis Backtest Dossier**:
  - Out-of-sample backtesting against standard Gaussian VaR across 4 historical benchmarks: 2008 Lehman GFC, 2020 COVID shock, 2021 Chip Shortage, and 2023 SVB run.
  - **Kupiec POF (Proportion of Failures)** and **Christoffersen Independence tests** proving the Student-$t$ Copula ($\nu=5$) accurately covers 99% tail losses without clustering violations.
- **Parameter Sensitivity Analysis**:
  - Comprehensive sensitivity audits testing variations in $\alpha$ ($\pm 10\%$), $\nu$ ($\pm 1.0$), and the solvency threshold ($\text{NetDebt/EBITDA} = 3.0 \pm 0.5$).
- **AST Import Isolation Guarantee**:
  - Formal proof that numerical calculations are completely isolated from LLM output (AST-verified pure computation) so no generative AI hallucination can alter regulatory capital calculations.

### 3.3 Pillar 3: InfoSec, Compliance & Governance
- **SAML 2.0 / OIDC Single Sign-On (SSO)** supporting Okta, Azure Active Directory, and Ping Identity.
- **Role-Based Access Control (RBAC)**: Segregated permissions for Risk Analysts, Senior Risk Managers / CROs (sign-off authority), and Model Validators / Compliance Auditors (read-only logs).
- **Cryptographic Audit Trail**: Append-only log recording who ran the simulation, portfolio SHA-256 hash, parameter vector, and execution timestamp.
- **Zero-Egress Private VPC Guarantee**: Air-gapped deployment via Kubernetes Helm charts (EKS, GKE, Red Hat OpenShift) where client holdings never leave their private network.

### 3.4 Pillar 4: Actionability (The "Prescriptive" Value Add)
Risk managers reject tools that only diagnose damage without proposing a remedy:
- **Tail-Risk Hedging Optimizer**: Computes the optimal capital-efficient hedge (e.g., *"Purchasing \$3.2M notional of out-of-the-money put options on SOXX and shorting \$5.0M high-yield debt reduces Expected Shortfall by 64% with an estimated premium cost of \$420,000"*).
- **One-Click Board-Ready PDF Generator**: Automated generation of a 3-page institutional executive summary (Headline drawdown, PnL waterfall, Top 5 bottleneck suppliers, balance-sheet contagion highlights, and actionable hedging plan with verbatim 10-K citations).
- **Scenario Diffing (A/B Testing)**: Side-by-side comparison of "Baseline Scenario" vs "Hedged Scenario" or "Current Quarter" vs "Previous Quarter".
