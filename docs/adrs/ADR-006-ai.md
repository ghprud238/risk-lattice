# ADR-006: Neuro-Symbolic & Privacy Boundary

## Status
Accepted

## Context
ContagionGraph architecture specification (Extended PRD v2.1 Section 29).

## Decision
LLM strictly confined to semantic parsing and post-mortem explanations with zero dollar egress.

## Revisit Trigger
Enterprise audited on-premise model approval.

## Consequences
- Guarantees deterministic mathematical reproducibility and strict privacy separation.
- Prevents database deadlocks and accidental vendor lock-in.
